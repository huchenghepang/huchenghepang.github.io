Mac 电脑的常见操作包括系统基础使用、快捷键操作、文件管理、窗口管理、网络设置等。以下是一些常见的 Mac 操作方法：

---

#### **一、基础操作**
##### 1. **触控板手势**

-   **单指点按**：左键点击
-   **双指点按**：相当于鼠标右键
-   **双指滑动**：滚动页面
-   **双指张开或捏合**：放大/缩小
-   **三指滑动**：快速拖动窗口（需要在设置中开启）
-   **四指上滑**：打开 **Mission Control**（显示所有窗口）
-   **四指下滑**：显示当前应用的所有窗口
-   **四指左右滑动**：切换全屏应用或桌面

##### 2. **菜单栏与 Dock**

-   **菜单栏**：位于屏幕顶部，包含应用菜单、WiFi、音量、时间等
-   **Dock（程序坞）**：默认在底部，可以拖拽常用应用放入其中
-   **隐藏/显示 Dock**：`Command + Option + D`

---

#### **二、常用快捷键**
##### 1. **窗口管理**

-   **`Command + W`**：关闭当前窗口
-   **`Command + Q`**：完全退出应用
-   **`Command + M`**：最小化窗口
-   **`Command + Tab`**：切换应用
-   **`Command + ~`**（波浪号）：在同一个应用的多个窗口之间切换
-   **`Command + Option + Esc`**：强制退出应用（相当于 Windows 的 `Ctrl + Alt + Del`）

##### 2. **文件与 Finder**

-   **`Command + Space`**：打开 **Spotlight**（全局搜索）
-   **`Command + Shift + N`**：新建文件夹
-   **`Command + Delete`**：删除文件
-   **`Command + Shift + Delete`**：清空废纸篓
-   **`Command + D`**：复制文件（在 Finder 中）

##### 3. **截图**

-   **`Command + Shift + 3`**：截取整个屏幕
-   **`Command + Shift + 4`**：截取选定区域
-   **`Command + Shift + 5`**：打开截图工具（可录屏）

##### 4. **剪切、复制、粘贴**

-   **`Command + C`**：复制
-   **`Command + X`**：剪切（Finder 里需要用 `Command + Option + V` 来剪切文件）
-   **`Command + V`**：粘贴
-   **`Command + Option + V`**：剪切并粘贴

---

#### **三、窗口 & 多任务管理**
##### 1. **Mission Control（多任务管理）**

-   **快捷键**：`F3` 或 `Control + 上箭头`
-   **触控板手势**：四指上滑

##### 2. **虚拟桌面（Spaces）**

-   **新建桌面**：打开 `Mission Control` 后，将窗口拖动到右上角的 “+” 处
-   **切换桌面**：
    -   `Control + 左/右箭头`
    -   触控板四指左右滑动

##### 3. **分屏操作**

-   **长按窗口左上角的绿色按钮**，然后选择左右屏幕分屏
-   **退出分屏**：点击窗口上方的 `退出全屏` 按钮

---

#### **四、软件与应用管理**
##### 1. **安装 & 卸载应用**

-   **从 App Store 下载应用**：打开 **App Store**，搜索并安装应用
-   **从网站下载 DMG 文件安装**：
    1.  双击 `.dmg` 文件
    2.  拖动应用图标到 **“应用程序”** 文件夹
-   **卸载应用**：
    -   直接拖到废纸篓
    -   用 `AppCleaner` 等工具彻底删除残留文件

##### 2. **打开未受信任的 App**

-   下载的软件可能会被 macOS 阻止：
    -   **方法 1**：`系统设置 -> 隐私与安全性 -> 允许打开`
    -   **方法 2**：`右键点击 App -> 打开`，绕过安全提示

---

#### **五、网络 & 连接**
##### 1. **WiFi & 热点**

-   点击 **右上角 WiFi 图标** 选择网络
-   个人热点共享：`系统设置 -> 共享 -> 互联网共享`

##### 2. **AirDrop（无线文件传输）**

-   **打开 AirDrop**：`Finder -> 侧边栏 -> AirDrop`
-   **发送文件**：拖拽文件到 AirDrop 界面，选择设备

##### 3. **蓝牙设备连接**

-   `系统设置 -> 蓝牙`，找到设备并连接

---

#### **六、磁盘 & 文件管理**
##### 1. **显示隐藏文件**

-   在 Finder 中按 `Command + Shift + .`（点号）

##### 2. **外接硬盘 & U 盘格式化**

-   Mac 默认格式：**APFS 或 macOS Journaled（HFS+）**
-   兼容 Windows：**exFAT**
-   格式化方法：`磁盘工具 -> 选择磁盘 -> 抹掉`

---

#### **七、终端常用命令**

打开终端：`Command + Space`，搜索 **终端（Terminal）**

##### 1. **常用命令**
```sh
# 显示当前目录
pwd

# 查看文件列表
ls -la

# 切换目录
cd 文件夹路径

# 创建文件夹
mkdir 文件夹名称

# 复制文件
cp 文件1 目标路径

# 移动文件
mv 文件1 目标路径

# 删除文件
rm 文件名

# 强制删除文件夹
rm -rf 文件夹名
```
---
##### 2. **Homebrew（软件包管理工具）**

Homebrew 可以安装各种软件：

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
---

常用命令：

```sh
brew install 软件名   # 安装软件
brew uninstall 软件名 # 卸载软件
brew list             # 查看已安装软件
```

#### **八、Mac 维护 & 常见问题**
##### 1. **释放存储空间**

-   `系统设置 -> 储存空间管理`
-   清理 `~/Downloads` 里的无用文件
-   使用 `AppCleaner` 删除残留软件数据

##### 2. **强制关机**

如果系统卡死，可以长按电源键 5-10 秒关机。

##### 3. **重置 NVRAM / PRAM（解决音量、显示等问题）**

1.  关机
2.  开机时 **按住 Option + Command + P + R** 直到听到两次启动声音

##### 4. **进入安全模式（排查问题）**

-   开机时 **按住 Shift**，直到进入登录界面
